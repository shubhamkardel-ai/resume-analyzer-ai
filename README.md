### 📄 Analyze Resumes • 🎯 Match Jobs • 🧠 Discover Skill Gaps • 🤖 Improve Careers

**Resume Analyzer AI** is an AI-powered resume intelligence platform designed to analyze resumes, evaluate ATS readiness, extract technical and professional skills, compare resumes against job descriptions, identify missing skills, generate visual analytics, and provide actionable AI-powered career feedback.

The system goes beyond a simple ATS score by combining **document processing, NLP-based skill intelligence, ATS evaluation, job matching, visual analytics, and AI-powered career coaching** into a unified application.

# 🎯 Core Objective

The main objective is to move beyond simply giving candidates a score.

Resume Analyzer AI transforms resume analysis into actionable career intelligence by helping users:

* Improve resume quality
* Identify missing technical skills
* Understand ATS performance
* Compare resume skills with job requirements
* Discover skill gaps
* Understand job alignment
* Prioritize improvement areas
* Receive AI-powered career recommendations

# ⚙️ Installation

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/shubhamkardel-ai/resume-analyzer-ai.git
cd resume-analyzer-ai
```

## 2️⃣ Create a Virtual Environment

### Windows

```bash
python -m venv .venv
```

Activate:

```bash
.venv\Scripts\activate
```

### Linux / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
```

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

# 🔐 Environment Configuration

If AI feedback requires external model access, create a `.env` file in the project root.

```env
HF_TOKEN=your_huggingface_token
HF_MODEL=your_model_name
```

Never commit `.env` to GitHub.

### Recommended `.gitignore`

```gitignore
.env
.venv/
__pycache__/
*.pyc
.idea/
.vscode/
```

---

# ▶️ Run the Application

Start the Gradio application:

```bash
python app.py
```

The application will launch locally.

Open the local Gradio URL shown in your terminal.

Typically:

```text
http://127.0.0.1:7860
```
